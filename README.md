# Scentiva — Shopify Theme

A custom Shopify theme developed for **Scentiva**, a luxury fragrance e-commerce storefront.

The project focuses on Shopify theme development using **Liquid, JavaScript, HTML, CSS, Shopify Metafields, product variants, Shopify Forms, and AJAX-based cart functionality**.

The theme was developed as a hands-on Shopify theme development project with an emphasis on reusable components, dynamic product data, responsive design, and maintainable theme architecture.

---

## ✨ Project Overview

Scentiva is a premium fragrance storefront designed around a clean, modern, and luxury-focused shopping experience.

The theme includes custom storefront components for:

- Luxury fragrance product presentation
- Dynamic product information
- Product variants and size selection
- Product metafields
- Custom Shopify sections
- Reusable Liquid snippets
- AJAX cart functionality
- Dynamic cart drawer updates
- Responsive layouts
- Custom homepage sections
- Custom "Our Story" page
- Collection-based fragrance organization
